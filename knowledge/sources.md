# Knowledge Base Sources

All agronomic facts in the system must be cited to one of these authoritative sources.

## Downloaded Sources

*Note: PDFs are too large for git tracking. Download these manually into `knowledge/sources/` using the links below.*

1. **UAS Dharwad Package of Practices (Maize)**
   - Used for: Fertilizer schedules, varieties, seed rate, spacing.
   - URL: [UAS Dharwad Publications](https://www.uasd.edu/)
2. **ICAR-IIMR Maize Advisories**
   - Used for: Fall armyworm management and Economic Threshold Levels (ETL).
   - URL: [ICAR-IIMR](https://iimr.icar.gov.in/)
3. **IMD North Karnataka Agromet Bulletins**
   - Used for: Weather-linked crop-stage specific advisories.
   - URL: [IMD NKA Bulletin](https://mausam.imd.gov.in/bengaluru/mcdata/nkafc.pdf)
4. **CIB&RC Pesticide Labels**
   - Used for: Chemical names and dosages. The absolute authority.
   - URL: [PPQS](https://ppqs.gov.in/)
